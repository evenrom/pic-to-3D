# End-of-day handoff — 2026-08-14

## Working product at the end of today

The local **pic to 3D** workflow is working end to end:

1. Upload one furniture photograph in the Next.js app.
2. Generate a textured GLB through Tripo image-to-model.
3. Recover a paid task after refresh using the task ID in the URL.
4. Optionally run Tripo Segmentation v2 after a 40-credit confirmation.
5. Preserve, preview, and download both the original and segmented GLBs.
6. Open the GLB in Blender 5.2 LTS.
7. Combine selected segmented parts into one named object with one material while preserving the source parts.
8. Prepare a copy at approximately 20,000 triangles, set real dimensions, and export OBJ.
9. Import the OBJ into Autodesk Revit 2027 at the correct size and orientation.

## Proven production settings

- Internal master format: GLB
- Revit transfer format: OBJ
- Blender target: approximately 20,000 triangles
- Blender OBJ export scale: `1.0`
- Forward axis: `X`
- Up axis: `Z`
- Revit Import Units: **Meters**
- Blender extension package: `blender_extension/dist/pic_to_3d_revit-0.2.1.zip`

The original `-X` forward setting was reversed in two real Revit furniture imports, so version 0.2.1 uses `X`.

## Sunday: prepare the work laptop

No Docker is required. VS Code is optional.

1. Install Git or GitHub Desktop.
2. Install Node.js 24 LTS.
3. Install Blender 5.2 LTS.
4. Confirm Autodesk Revit 2027 is available.
5. Clone `https://github.com/evenrom/pic-to-3D.git` into a local GitHub folder.
6. Check out the published feature branch if its pull request has not yet been merged; otherwise use `main`.
7. Create `.env.local` in the repository root.
8. Retrieve the Tripo key from Google Password Manager and add `TRIPO_API_KEY=tsk_...` to `.env.local` locally. Never send or commit this file.
9. Run `npm install` and then `npm run dev` (`npm.cmd` can be used in PowerShell if script execution blocks `npm.ps1`).
10. Open `http://localhost:3000` and perform a no-cost page check before starting a paid generation.
11. In Blender, install `blender_extension/dist/pic_to_3d_revit-0.2.1.zip` from disk and enable the extension.
12. Run one known model through Blender and Revit to confirm the work laptop uses Forward X, Up Z, scale 1.0, and Revit meters.

## Important limitations

- Tripo segmentation identifies semantic geometry; it does not guarantee exact material boundaries.
- Replacing several image-textured Tripo materials with one material can change appearance because their textures and UV layouts can differ.
- The Blender merge tool preserves and hides source parts by default so the operation remains reversible.
- The API key belongs only in `.env.local` locally or in a protected server-side environment variable during future deployment.
